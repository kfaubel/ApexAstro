# Getting Started with ApexAstro

Welcome to ApexAstro — an image viewer and analysis tool for astronomical imaging.

The first time you run the application, you will be prompted to pick the image format you are using.  This is either:
- N.I.N.A. - This uses fits metadata generated by the N.I.N.A. application.
- ASIAIR - This uses fits metadata generated by the ASIAIR application.
- Custom - This lets you configure the metadata yourself in the Option menu.

# Browse the Images
- Select a folder of fits files to view.  
- Click any file in the list to view it
- Click the icon in the Info column to see all of the fits header data
- Pan and zoom the image to see details
- You can switch to full screen or pop out the image pane and move to another monitor.
- Press play to blink the images for a quick visual inspection.
- Click the graph icon to see a plot of the metadata values for all of the images.
- Click in the checkbox for each row to mark the image.  This is typically used to cull unwanted images from the selection.
- Click Move Selected... to move the selected files to another directory or send to the recycle bin

# Additional Metadata
If you are using N.I.N.A. to capture your images, you can configure it to write additional metadata into the filename.  This includes RMS, HFR, Stars, and Eccentricity.  You can then go to Options -> Custom Keywords and add columns for these values. See Help for more on setting this up.

Once you have this additional metadata in the filename, you can sort on these columns and quickly cull out the bad images.  You can also use the Auto Select dialog to automatically select images based on thresholds for RMS, HFR, Stars, and Eccentricity.
